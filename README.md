# Проект парсинга pep
## Парсер документации Python
## Развёртывание проекта:
```bash
git clone https://github.com/TheDarkSide90/bs4_parser_pep.git
```
```bash
cd bs4_parser_pep
```
```bash
python -m venv venv
```
```bash
source venv/Scripts/activate
```
```bash
cd src
```
## Помощь по парсеру
```bash
python main.py -h
```
## Очистить кеш парсера
```bash
python main.py -c
```
## Дополнительные способы вывода данных:
```bash
python main.py -o
```
